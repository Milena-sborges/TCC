# Biblioteca Emocional

Sistema de recomendação de livros baseado no estado emocional do usuário.

## Sobre o projeto

Este projeto foi desenvolvido como Trabalho de Conclusão de Curso (TCC) do curso de Análise e Desenvolvimento de Sistemas.

O objetivo é recomendar livros de domínio público utilizando técnicas de filtragem por conteúdo, considerando o estado emocional informado pelo usuário.

Os livros utilizados são provenientes do Projeto Gutenberg, que disponibiliza obras em domínio público.
